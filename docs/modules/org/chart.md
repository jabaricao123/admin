# 组织管理 · 组织架构图

| 项 | 值 |
|---|---|
| 路由 | /org/chart |
| 状态 | P1，待立项 |
| 模块 | [org](../README.md#2-组织管理-orgp0) |

## 目的

可视化树形组织图：部门层级 + 负责人 + 人数，点击部门下钻人员列表。

## 功能需求

1. 树形图：节点 = 部门（名称、负责人、人数）；≥4 级时折叠远端分支。
2. 交互：点击节点展开/收起子树；「查看人员」打开该部门人员抽屉（只读）。
3. 移动端：改为纵向折叠树（accordion 式），节点可点开看部门摘要。
4. 截图导出（P2，可延后）。

## 数据模型

只读消费：`departments_v`（含 path）+ `department_headcount()` RPC。不建新表。

## RLS

- 同 departments SELECT 策略；人员抽屉走 profiles 本人可见范围。

## 界面规格

- 桌面用 CSS 布局自绘树（连线用伪元素），不引入图形库；主题用 `--primary` 与 `--accent`。
- 空树显式空态（「暂无部门，请先维护部门」）。

## 依赖与契约

- departments/positions 已交付；人员抽屉复用 org/users 的只读展示逻辑。

## 验收标准

- 10 级深树：默认折叠至 3 级可逐级展开，500 节点内首屏渲染 < 2s；移动端可完整浏览与下钻。
