# 权限管理 · 权限审计

| 项 | 值 |
|---|---|

## 目的

权限域专用审计视图：角色/授权/范围变更记录与越权尝试告警展示，数据来自审计中心。

## 功能需求

1. 变更记录：时间、操作人、对象（角色/菜单授权/数据范围）、动作、前后差异。
2. 越权尝试列表：被 RLS/守卫拒绝的访问尝试（模块、路由、用户、时间）。
3. 筛选：操作人、对象类型、时间段；导出跳转报表中心导出管道。

## 数据模型

只读消费：audit 公开视图 `audit_operations_v`（module = 'access' 过滤）+ `audit_denied_v`（越权尝试：user/module/route/reason/time；写入路径 = 应用层捕获 42501/守卫拒绝后调 audit_log('denied')，见 audit/operations.md）。本模块不建表。

## RLS

- 仅 admin 可见（页面守卫 + audit 侧 RLS 双保险）。

## 界面规格

- 标准 列表页模式：工具栏 + Table；移动端卡片。
- 前后差异列渲染为旧值→新值（删除线 + 主色新值）。

## 依赖与契约

- audit 中心已交付（提供两个视图）；越权尝试的写入方是各模块守卫/RLS（经 audit_log）。
- 导出走 report 的统一管道（INDEX 职责表）。

## 验收标准

- 角色矩阵每次勾选变更均可在本页检索到且 diff 正确。
