## 目的

系统信息页：版本号、更新记录、技术栈与许可信息，问题上报入口。

## 功能需求

1. 版本信息：当前版本（读 package.json version，服务端注入）、构建时间、git commit（构建时注入）。
2. 更新记录：CHANGELOG 结构化展示（版本分组、日期、变更类型 Badge），数据来自仓库 CHANGELOG 文件。
3. 技术栈摘要：只读展示（Next.js / Supabase 项目 ID 掩码等，不含敏感配置）。
4. 许可信息：许可类型与归属（商业化前展示内部使用声明）。
5. 问题上报：链接到 issue tracker（内部通道说明）。

## 数据模型

不落库：版本/commit 构建时注入环境；CHANGELOG 文件随仓库走。

## RLS

- 登录用户可见；无敏感信息（所有展示内容过安全审查）。

## 界面规格

- 信息卡片 + 时间线式 changelog；移动端单列。

## 依赖与契约

- CHANGELOG.md 仓库根维护，本页只读渲染（发布流程同步更新 CHANGELOG 列入规范）。

## 验收标准

- 展示版本与部署包一致；commit 与实际部署对应；页面无任何密钥/内部地址泄露。
