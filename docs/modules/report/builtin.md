# 报表中心 · 预置报表

| 项 | 值 |
|---|---|
| 路由 | /report/builtin |
| 状态 | P1，待立项 |
| 模块 | [report](../README.md#5-报表中心-reportp1) |

## 目的

开箱即用的统计报表：人员统计、部门分布、操作活跃度，直接消费各模块公开视图。

## 功能需求

1. 报表卡片：按目录组织（组织域 / 审计域 / 后续业务域）。
2. 内置三张（首期）：
   - 人员统计：总数、在职/停用、按角色分布；
   - 部门分布：各部门人数（含子部门聚合）、编制 vs 在岗；
   - 操作活跃度：按日操作量、活跃用户 Top10（数据来自 audit 摘要）。
3. 每张报表：时间范围筛选（近 7/30/90 天/自定义）+ 图表（recharts，`--chart-1..5`）+ 数据表格切换视图。
4. 导出按钮走统一导出管道（见 exports.md）。

## 数据模型

只读消费：org `departments_v`/`department_headcount()`、profiles 统计 RPC、audit `audit_operations_v` 聚合。不建业务表。

## RLS

- 数据按当前用户数据范围过滤（scope helper）；admin 全量。

## 界面规格

- 卡片入口 → 报表页（图 + 表 toggle）；移动端图表降级为简化表格。
- 空数据显式空态。

## 依赖与契约

- 只允许引用各模块 `_v` 视图与公开 RPC（INDEX 规则 1）。

## 验收标准

- 数字与来源模块页面一致（同源视图）；数据范围过滤后非 admin 不见全量。
